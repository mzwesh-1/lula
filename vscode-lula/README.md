# Lula for VS Code

Write C++ in all 10 written official South African languages.

- Syntax highlighting for all Lula languages
- Hover a keyword to see its C++ meaning
- Keyword completion
- Errors shown in the editor on save (in your language's keywords)
- 🤟 South African Sign Language: hover a keyword → **Show SASL sign** (or Ctrl+Alt+S) to play the sign video
- ▶ Run button, "Show C++" side view, "Export for Arduino (.ino)"

Name files with the language code: `program.zu.lula`, `.xh.lula`, `.ss.lula`, `.nr.lula`, `.st.lula`, `.tn.lula`, `.nso.lula`, `.ts.lula`, `.ve.lula`, `.af.lula`.
Requires a C++ compiler (g++/clang, or avr-g++ / arm-none-eabi-g++ for embedded) — set `lula.compilerPath`.
